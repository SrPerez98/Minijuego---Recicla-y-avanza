## Aprendizajes
- Aprendí a usar GitHub para trabajar en equipo: crear un repositorio, invitar colaboradores, organizar carpetas y hacer commits identificables por cada integrante.
- Aprendí que un README claro y una estructura ordenada permiten que cualquier persona entienda y ejecute el proyecto sin ayuda.
- Aprendí a aplicar criterios de accesibilidad (WCAG 2.2 y DUA) en un juego, y que conviene pensarlos desde el diseño y no al final.
- Aprendí que el rol de QA va más allá de probar: consiste en documentar con claridad lo que se encuentra para que el equipo pueda mejorarlo.
